# HiveAgents Runtime 0.1.0-beta.5

Beta de un único paquete TypeScript para trabajar con los CLI de agentes instalados. Node.js 22.16 o posterior y aplicación ESM. macOS es la plataforma de referencia.

- Inicio rápido incluido en el paquete. Ejecuta un CLI local determinista con el SDK y verifica el resultado sin credenciales.
- Diagnóstico `doctor --share` con campos acotados y errores públicos de memoria con mensajes fijos.
- Routing aprendido con perfiles de ejecución por candidato, contrato de salida nativo ligado a la evidencia y abstenciones tipadas.
- Guía para integrar los proveedores, verificar entregables y reportar problemas con datos reproducibles.
