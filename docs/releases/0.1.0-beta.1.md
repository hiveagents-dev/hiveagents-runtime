# HiveAgents Runtime 0.1.0-beta.1

HiveAgents Runtime es un SDK TypeScript local-first para integrar agentes a través de CLIs instalados. La beta apunta a flujos supervisados en macOS con Node.js 22.16 o posterior. Incluye Claude Code y Codex, adaptadores separados para Gemini y Antigravity, y una app de triage que se puede probar offline.

- Los workflows dinámicos propagan detenciones de infraestructura del control de admisión y esperan la liquidación de la ejecución y la devolución del cupo. Una respuesta vencida se descarta y su uso reportado se conserva.
- Control aplica un plan privado validado. `Agent.ready()` devuelve un diagnóstico inmutable.
- El historial reserva capacidad para cerrar las ejecuciones que admite. El verificador prueba el SDK y los dos adaptadores como tarballs instalados en una app externa.

Probá primero la [demo offline](../../examples/README.md#document-triage-and-restart). El [checklist de distribución](../release-checklist.md) explica cómo construir y verificar los tres tarballs. Las pruebas offline usan CLIs simulados. Para sesiones reales, consultá la [matriz de capacidades](../capability-matrix.md).

## Texto para el anuncio

Preparamos la primera beta de HiveAgents Runtime, un SDK TypeScript para ejecutar y reanudar workflows de agentes en aplicaciones locales. Incluye Claude Code y Codex, con adaptadores para Gemini CLI y Antigravity CLI. Podés probar un workflow recuperable sin cuenta ni consumo de modelos, y sumar un CLI autenticado cuando quieras ejecutar agentes reales. Esta beta apunta a flujos supervisados en macOS. Buscamos feedback sobre instalación, diagnóstico de proveedores y recuperación de ejecuciones.
