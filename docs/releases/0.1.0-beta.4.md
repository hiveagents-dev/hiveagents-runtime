# HiveAgents Runtime 0.1.0-beta.4

Esta beta agrega Antigravity CLI **1.5.15** al contrato de compatibilidad del adaptador `exec`. Mantiene la entrada única `hiveagents-runtime`, los cuatro proveedores incluidos y la validación de los flags de cada versión. El adaptador exige intención `edit` explícita con el perfil de revisión del CLI. Probá en un directorio dedicado, con autenticación local y un modelo habilitado para tu cuenta.

```sh
npm install https://github.com/hiveagents-dev/kanban-tutorial/releases/download/v1.0.0/hiveagents-runtime-0.1.0-beta.4.tgz
npx --no-install hiveagents-runtime doctor
```

La apertura concurrente del almacén SQLite de routing tolera que otra conexión elimine un archivo auxiliar al cerrarse. Los controles de propiedad y permisos siguen activos.

Las pruebas del adaptador cubren turnos y reanudación para 1.5.15 y rechazan una versión vecina que no forma parte del contrato. El comando de diagnóstico verifica instalación y capacidades. El tutorial incluye los pasos y la evidencia de proveedores y del tablero. [Tutorial de HiveAgents](https://github.com/hiveagents-dev/kanban-tutorial)
